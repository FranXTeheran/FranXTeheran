## ◈ &nbsp; Proyecto Destacado

<br/>

<div align="center">

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                   │
│   ◈  Banquito — Plataforma de gestión de ahorro grupal           │
│                                                                   │
└─────────────────────────────────────────────────────────────────┘
```

</div>

**[💰 banquito-demo](https://github.com/FranXTeheran/banquito-demo)** &nbsp;·&nbsp; [🌐 Demo en vivo](https://banquito-demo.vercel.app)

Plataforma web fullstack para la **gestión de fondos compartidos** — pensada para familias, equipos y grupos que manejan dinero colectivo sin herramientas adecuadas.

**Tecnologías:** `React (Vite)` `Node.js` `Express` `PostgreSQL` `Prisma ORM` `TailwindCSS` `JWT`

**Lo que resuelve:**
- 🔐 &nbsp; Autenticación con roles — Administrador y Usuario
- 📊 &nbsp; Panel por rol con resumen de ahorro e historial
- ➕ &nbsp; Registro de aportes con cálculo de totales y promedios
- 📱 &nbsp; Diseño responsivo, listo para producción

```
React (Vite) → Axios → API REST (Express) → Prisma ORM → PostgreSQL
```
